# Atelier JavaScript – Fonctions

## Description

Ce projet contient plusieurs fonctions JavaScript permettant de manipuler des chaînes de caractères, des tableaux et d'effectuer des calculs mathématiques.

## Fonctionnalités

### Manipulation de chaînes de caractères

* Inverser une chaîne de caractères.
* Compter le nombre de caractères d'une chaîne.
* Mettre en majuscule la première lettre de chaque mot.

### Manipulation de tableaux

* Trouver la valeur maximale d'un tableau.
* Trouver la valeur minimale d'un tableau.
* Calculer la somme des éléments d'un tableau.
* Filtrer les éléments d'un tableau selon une condition.

### Fonctions mathématiques

* Calculer la factorielle d'un nombre.
* Vérifier si un nombre est premier.
* Générer la suite de Fibonacci.

## Technologies utilisées

* JavaScript (ES6)

## Exécution

1. Clonez le dépôt :

```bash
git clone <url-du-depot>
```

2. Accédez au dossier du projet :

```bash
cd <nom-du-projet>
```

3. Exécutez le fichier JavaScript avec Node.js :

```bash
node index.js
```

Ou ouvrez le fichier dans la console de votre navigateur.
